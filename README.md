# EDSIP MP Capture (Chrome MV3) — Wildberries + Ozon

Пассивно копирует JSON-ответы, которые страница маркетплейса **уже получила** в вашем обычном браузере.
Своих запросов не делает, cookies и заголовки не читает, токены и трекинг вырезаются (`<redacted>`).

## Что сохраняется (формат `edsip-mp-capture/2`)
Конверт файла (один файл = один запрос или одна зона): `schema: "edsip-mp-capture/2"`, `capture_id` (uuid4), `marketplace`,
`extension_version`, `saved_at`, `run_started_at`/`run_ended_at`, `query`, `zone` (категория/бренд), `tabs`, `format: pretty-1`,
`context` — `site_host`, `region_hint {dest, curr}`, а также всегда `curr`, `dest`, `spp`, `snapshot_at` (время последнего ответа выдачи)
и `pages`/`page`; `stats` (справочно); `records[]` — `url` (очищенный), `kind`, `status`, `ts`, `redirected`, `tab`, `query`/`zone`,
`body` (объект), `body_sha256` (sha256 канонического JSON очищенного body: ключи отсортированы, компактно, UTF-8 без \u-экранирования = Python `json.dumps(sort_keys=True, separators=(',',':'), ensure_ascii=False)`). Пример: `tests/fixtures/sample_v2.json`.

- **WB** (wildberries.ru/.by): поиск v18, **страницы категорий** (`kind: category`) и **зоны брендов** (`kind: brand_zone`),
  u-card v4 detail/list (`card`), `card.json` (`card_info`), `rich_v1.json` (`card_rich`: наличие, число блоков, URL картинок),
  отзывы (`feedbacks`: только счётчики `feedback_count, valuation, with_photo, with_text, with_video, distribution`,
  `reviews_total`, `reviews_loaded`, `reviews_2026`, `with_answer`, `reviews_by_year`), вопросы (`question_count`).
- **Ozon** (ozon.ru, ozon.by): `/api/entrypoint-api.bx/page/json/v2`, `/api/composer-api.bx/page/json/v2` — поиск, категории,
  бренды, карточка. Формат Ozon **не проверен на живой HAR**.
- **Цены собираются полностью и как есть** (без пересчёта — нормализует бэкенд): `sizes[].price {basic, product, total, wallet,
  logistics, return, cashback}`, `saleConditions`, продавец `supplier`, `supplierId`, `supplierRating`; в detail — `sizes[].stocks`
  и `promotions`; валюта/регион/СПП — в `context` и URL.
- **Только разрешённые поля** (allowlist по типу ответа в `page_hook.js`): всё, чего нет в списке, отбрасывается
  (в т. ч. неизвестные поля, данные пользователя, трекинг, `meta`; шифрованный `logs` рекламы не хранится — вместо него `is_ad_logs: true/false`, `viewFlags` целиком; `colors` сохраняется). Поверх — удаление ключей-секретов и JWT.
  Тексты отзывов, имена авторов, фото отзывов и **файлы изображений не сохраняются** — только URL и метаданные.

## Сохранение файлов (⚙ Настройки)
- **В «Загрузки» → подпапка** (по умолчанию `EDSIP/inbox`, т. е. `~/Downloads/EDSIP/inbox/`). Chrome разрешает расширениям
  писать только внутри «Загрузок». Флажок «Отдельные подпапки wb/ и ozon/».
- **В выбранную папку** (File System Access API, кнопка «Выбрать папку…» на странице настроек), например
  папку для загрузки в ваш пайплайн. Доступ хранится в браузере; если Chrome его сбросил — спросит при сохранении,
  при отказе файл уйдёт в «Загрузки».
- Имя: `<маркетплейс>_<запрос>_<ГГГГ-ММ-ДД>_<ЧЧ-ММ-СС>[_runN].json` (местное время). Файлы не перезаписываются:
  для папки проверяется существование (`_run2`, `_run3`…), для «Загрузок» — история сохранений + `uniquify` Chrome.
- В файле: `extension_version`, `run_started_at` / `run_ended_at` (первая/последняя запись сбора, UTC), `saved_at`.
- В окне — «Последние сохранения»: имя, время, путь (последние 30).

## Обновление из окна расширения
1. Репозиторий публичный — **по умолчанию токен не используется**. Только если упираетесь в лимит GitHub API без авторизации
   (60 запросов/час с одного IP): ⚙ Настройки → **fine-grained** токен **только на чтение** (Public repositories read-only или
   только этот репо с Contents: Read-only, короткий срок). Хранится открытым текстом в `chrome.storage.local` — не давайте прав на запись.
2. «Указать папку расширения…» → `~/EDSIP/edsip-mp-capture` (проверяется `manifest.json`, имя «EDSIP MP Capture»).
3. «Проверить обновления» (в окне или настройках) → «Обновить до vX»: zip скачивается и распаковывается в браузере,
   **сначала проверяется подпись**: `SHA256SUMS` релиза подписан ed25519 (публичный ключ зашит в `lib/updater.js`,
   закрытый ключ хранится вне репозитория), и sha256 zip должен совпасть. Без подписи/при несовпадении обновление отменяется.
   В папку пишутся только файлы расширения из белого списка путей; текущие файлы копируются в `.prev/`, затем перезапуск.
4. Флажок «Проверять раз в день»: при новой версии на значке «↑» (если нет других счётчиков) и подсказка у значка.

**Ограничения:** нужен Chrome 137+ (Ed25519 в WebCrypto; иначе — обновление через Терминал), zip без ZIP64/шифрования; папку надо указать один раз,
но Chrome может снова спросить доступ после перезапуска; git-клон из окна не обновляется (`git pull`); если запись
прервалась — восстановить из `.prev/` или выполнить `bash ~/EDSIP/update-extension.sh`. Новые разрешения в manifest
(если появятся) Chrome может потребовать подтвердить на chrome://extensions. Без указанной папки — команда для Терминала.

## Окно расширения
- Карточки WB и Ozon: запрос, хост, товаров (уникальных), страниц, реклама (шт. и %), карточек, блокировки, записей.
- Статус: «Захват WB/Ozon» на нужной вкладке, «Автопрокрутка», «Не WB/Ozon».
- «Сохранить» — файл по настройкам (см. «Сохранение файлов»): `wb_<запрос>_<дата>_<время>.json` или `ozon_…`
  (схема `edsip-mp-capture/1`, поле `marketplace`, читаемый JSON `pretty-1`). Дальше файл кладётся в папку для загрузки в ваш пайплайн.
- «Очистить» — удаляет данные только этого маркетплейса (с подтверждением).

## Автопрокрутка (по вкладкам)
- «▶ Запустить» — на текущей вкладке; флажок «во всех открытых вкладках этого маркетплейса» запускает и в остальных
  открытых вкладках WB/Ozon, но не больше 3 одновременно на маркетплейс (лишние пропускаются с сообщением).
- Каждая вкладка прокручивается независимо: своя цель, свой счётчик товаров (по записям этой вкладки), своя причина остановки.
- Работает и в фоновых вкладках: паузы отсчитывает service worker (таймеры страницы в фоне Chrome замедляет до 1 раза
  в секунду/минуту), страница делает только один шаг прокрутки по команде; в фоне шаг без анимации + событие `scroll`.
  Будильник `alarms` раз в 30 с возобновляет задания, если Chrome перезапустил service worker.
- В окне — список всех прокручиваемых вкладок: маркетплейс, запрос, прогресс, «Стоп» по каждой и «■ Остановить все».
- Остановка: цель (0 = до конца), 4 раза подряд внизу нет нового, 20 мин, закрытие вкладки, блокировка, вручную.

## Защита от блокировок
- Ответ 403/429 (WB также 498) на отслеживаемых запросах или капча/антибот-страница на вкладке → автопрокрутка
  останавливается, в окне появляется красное предупреждение, на значке «!». По умолчанию ставятся на паузу **все**
  прокручиваемые вкладки этого маркетплейса (флажок можно снять — тогда только текущая). Пока предупреждение не снято
  кнопкой «Понятно, снять», новая автопрокрутка этого маркетплейса не запускается. Капча не решается и не нажимается.
- Не больше 3 одновременно прокручиваемых вкладок на маркетплейс (в окне показывается «N из 3» и предупреждение).
- Темп: «Обычно» / «Быстро». На Ozon даже «Быстро» оставляет умеренные паузы (1,1–2 с, длинные 3–5,5 с);
  «Обычно» на Ozon — 1,4–3 с (длинные 4,5–9 с). WB: 0,9–2,2 с / «Быстро» 0,45–1 с.

## Отдельные окна и фоновые вкладки
- «⧉ Открыть в отдельном окне» — переносит текущую вкладку в своё обычное (не свёрнутое) окно.
- Флажок «каждую вкладку — в своё окно рядом» при запуске раскладывает прокручиваемые вкладки плиткой по экрану
  (до 3 в ряд, по размеру доступной области экрана); «▦ Разложить окна» — то же для уже идущих прокруток.
- Если прокручиваемая вкладка скрыта (`document.visibilityState = hidden`), в списке появляется предупреждение
  и кнопка «Вынести в окно»: скрытые вкладки сайт может не догружать.
- Прокручиваемым вкладкам ставится `autoDiscardable=false` (Chrome не выгрузит их), после остановки — обратно.

### Экономия памяти Chrome (настраивается только вручную)
1. Откройте `chrome://settings/performance` (в окне расширения есть кнопка «Открыть настройки производительности»).
2. В блоке «Экономия памяти» → «Всегда оставлять активными эти сайты» → «Добавить».
3. Добавьте: `wildberries.ru`, `wildberries.by`, `ozon.ru`, `ozon.by`.

## Картинки
Файлы изображений **не скачиваются и не сохраняются**. В экспорт попадает только то, что уже есть в JSON-ответах:
WB поиск — число фото `pics` у товара; WB `card.json` — `media.photo_count` (+ признак видео), по нему и `nm`
модуль ingest строит URL `basket-XX.wbbasket.ru/.../images/big/N.webp`; Ozon — URL картинок CDN внутри `widgetStates`
(как их отдаёт страница). Отзывы сокращаются до счётчиков (в т. ч. «с фото»), их фото не сохраняются.

## Разделение одновременных сборов
Каждая запись получает `tab` (id вкладки) и `query` (запрос поиска; для карточек — последний запрос этой вкладки).
«Сохранить» создаёт **отдельный файл на каждый запрос** (`ozon_<запрос>_<дата>_<время>.json`; при совпадении имени
Chrome добавит « (1)»); в файле есть поля `marketplace`, `query`, `tabs`.

## Установка на Mac (один раз)
Папка расширения всегда одна и та же: `~/EDSIP/edsip-mp-capture` — тогда Chrome сохраняет ID расширения и собранные данные.
1. Скачать скрипт и установить (нужны только curl и python3 из macOS):
   ```bash
   mkdir -p ~/EDSIP && curl -fsSL https://raw.githubusercontent.com/Jommmain/edsip-mp-capture/main/update-extension.sh -o ~/EDSIP/update-extension.sh && bash ~/EDSIP/update-extension.sh
   ```
2. Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `~/EDSIP/edsip-mp-capture`.

## Обновление
```bash
bash ~/EDSIP/update-extension.sh
```
Затем в окне расширения «⟳ Перезагрузить расширение» (или ⟳ в `chrome://extensions`) и F5 на вкладках WB/Ozon.
Скрипт идемпотентный: при той же версии ничего не делает (`--force` — переустановить); проверяет manifest; держит
бэкап прошлой версии в `~/EDSIP/edsip-mp-capture.prev`.

Репозиторий публичный: скрипт работает без авторизации. Если упёрлись в лимит GitHub API — `GITHUB_TOKEN=… bash ~/EDSIP/update-extension.sh`
(токен только на чтение) или `gh auth login` (скрипт использует gh как запасной путь). Режим git: `EDSIP_MODE=git EDSIP_GIT_DIR=~/EDSIP/repo bash ~/EDSIP/update-extension.sh`
(после `git clone https://github.com/Jommmain/edsip-mp-capture.git ~/EDSIP/repo`).

## Разработка
- Файлы расширения лежат в корне репозитория; тесты: `for t in tests/*.test.js; do node $t; done`.
- Сборка zip (файлы в корне архива): `bash build.sh` → `dist/edsip-mp-capture-<версия>.zip`.
- Релиз: поднять `version` в `manifest.json`, `bash build.sh` (создаёт `dist/SHA256SUMS` и подписывает его ключом
  `EDSIP_SIGNING_KEY`, по умолчанию `~/.config/edsip-signing/release-ed25519.pem`, **не в репо**), затем
  `gh release create v<версия> dist/edsip-mp-capture-<версия>.zip dist/SHA256SUMS dist/SHA256SUMS.sig`.
- `update-extension.sh` проверяет sha256 по `SHA256SUMS` всегда и подпись — если `openssl` умеет ed25519 (LibreSSL в macOS может
  не уметь: `brew install openssl`; `EDSIP_REQUIRE_SIGNATURE=1` — отказ без проверки подписи).
- Этап 2 (POST в EDSIP) — заглушка `lib/transport_post.js`, **выключена** (`ENABLED=false`), нигде не подключена, домена EDSIP
  в правах нет; заголовок `X-EDSIP-Extension-Token`. Этап 1 — файл в папку для загрузки в ваш пайплайн.

## Права расширения (минимум)
- `storage` — записи и настройки; `unlimitedStorage` — ответы выдачи крупные (до ~0,7 МБ), 3000 записей не влезают в 10 МБ квоты;
- `downloads` — сохранение файла в «Загрузки» (способ по умолчанию); `alarms` — шаги автопрокрутки и ежедневная проверка обновлений;
- host-доступ к wildberries/ozon — перехват ответов, адреса вкладок для «во всех вкладках» (вместо права `tabs`);
  к `api.github.com`/`github.com`/хостам файлов релизов — только для обновления. Права `tabs` и `activeTab` убраны.
