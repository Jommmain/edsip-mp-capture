Куда сохранять файлы

Загрузки/

Chrome разрешает расширениям сохранять только внутри «Загрузок». Пусто — прямо в «Загрузки».

не выбрана

Например, папку для загрузки в ваш пайплайн. Если доступ к папке пропал, Chrome спросит разрешение при сохранении; при отказе файл уйдёт в «Загрузки».

Имя файла: — местное время; существующие файлы не перезаписываются (добавляется _run2, _run3…).

Обновления из GitHub

Репозиторий Jommmain/edsip-mp-capture публичный — токен не нужен. Необязательно: токен GitHub только на чтение, если упираетесь в лимит API без авторизации (60 запросов/час). Хранится только в этом браузере (chrome.storage.local).

не указана

Выберите ~/EDSIP/edsip-mp-capture (ту, что загружена в chrome://extensions). Проверяется manifest.json. Если это git-клон — обновляйте через git pull.


  
Если папка не указана: в Терминале bash ~/EDSIP/update-extension.sh, затем ⟳ в окне расширения.
    Предыдущая версия сохраняется в подпапке .prev/.
